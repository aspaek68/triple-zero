# Godot Engine
================

### Overview

Godot is an open-source game engine developed by Juan Linietsky and Ariel Manzur, initially released in 2014. It is designed to create both 2D and 3D games targeting various platforms, including PC, mobile, web, consoles, and virtual reality platforms.

### Features

*   **Multi-Platform Support**: Godot allows developers to create games for multiple platforms, including desktop, mobile, web, consoles, and virtual reality platforms, without licensing fees.
*   **Hierarchy of Nodes**: Godot uses a hierarchy of nodes to facilitate the development experience, enabling developers to create more specialized node types that inherit behavior.
*   **GDScript**: Godot supports the integrated language GDScript, as well as C++ and C# for making games.
*   **GDNative (GDExtension)**: Godot includes a facility for creating bindings with other languages, including C and C++.
*   **Visual Coding**: Although removed from the core engine in Godot 4.0, VisualScript was originally supported for visual coding.
*   **Cross-Platform Deployment**: Godot enables developers to deploy their games across multiple platforms.

### Supported Platforms

*   **Desktop Platforms**: Linux, macOS, Windows
*   **Mobile Platforms**: Android, iOS
*   **Web Platform**: HTML5, WebAssembly
*   **Virtual Reality Platforms**: HTC Vive, Valve Index, Oculus Rift, Oculus Go, Oculus/Meta Quest, Windows Mixed Reality, Apple ARKit
*   **Consoles**: Although popular consoles are not officially supported, games can be ported to consoles through third-party companies.

### Scripting Languages

*   **GDScript**: Integrated language for making games
*   **C++**: Officially-supported language
*   **C#**: Officially-supported language
*   **Rust**: Community-supported language
*   **Nim**: Community-supported language
*   **Swift**: Community-supported language
*   **JavaScript**: Community-supported language

### API Documentation

*   Godot's API documentation can be found in the [official documentation](https://docs.godotengine.org/en/stable/).

### Example Use Cases

*   Creating 2D and 3D games for PC, mobile, web, consoles, and virtual reality platforms
*   Developing games using GDScript, C++, or C#
*   Using GDNative (GDExtension) for creating bindings with other languages
*   Creating immersive applications for Meta Quest devices
