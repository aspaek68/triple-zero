**Unreal Engine**
================

### Overview

Unreal Engine is a 3D computer graphics game engine developed by Epic Games, initially released in 1998 for PC first-person shooters. It has since been used in various genres of games and adopted by other industries, including film and television.

### Key Facts

* Written in C++
* Supports a wide range of platforms, including desktop, mobile, console, and virtual reality
* Latest generation, Unreal Engine 5, was launched in April 2022
* Source code available on GitHub
* Commercial use is granted based on a royalty model, with Epic charging 5% of revenues over $1 million

### Release Timeline

* Unreal Engine 1: 1998
* Unreal Engine 2: 1999-2000
* Unreal Engine 3: 2007-2013
* Unreal Engine 4: 2015-2021
* Unreal Engine 5: 2022
* Unreal Engine 6: TBA (announced in 2026)

### Features

* Nanite: virtualized geometry system for high-quality meshes with automatically generated Level of Detail
* Lumen: dynamic global illumination and reflections system using software and hardware ray tracing
* Blueprints: visual scripting system introduced in Unreal Engine 4
* UnrealScript: native scripting language used for authoring game code and gameplay events

### APIs

* DirectX 9
* 3DFX Glide API
* UnrealScript (C++-based)

### Example Use Cases

* Games: Fortnite, Rocket League, Gears of War
* Film and Television: supported various productions, including the 2019 film "Dune"
* Virtual Reality: used in various VR applications and experiences

### Scripting

* UnrealScript: native scripting language used for authoring game code and gameplay events
* C++
* Java

### License

* Source-available: commercial software with royalty model for commercial use
* Royalty model: 5% of revenues over $1 million, waived for games published exclusively on the Epic Games Store
