**Game Engine**
================

A game engine is a software framework primarily designed for the development of video games. It typically includes relevant libraries and support programs.

**Key Facts**

* Game engines provide a suite of visual development tools and features for developing video games across platforms.
* Common core functionalities of game engines include:
	+ 2D or 3D renderer
	+ Physics engine
	+ Audio engine
	+ Scripting
	+ Animation
	+ Artificial intelligence
	+ Networking
	+ Streaming
	+ Memory management
	+ Threads
	+ Localization support
	+ Scene graph
	+ Cinematics
* Game engines aim to economize game development through reuse or adaptation of abstractions built into the engine.

**APIs and Examples**

* Some popular game engines include:
	+ Unity
	+ Unreal Engine
	+ Godot
	+ CryEngine
	+ Source Engine
* APIs for game engines often include:
	+ Unity API: UnityScript, C#, and Unity Editor API
	+ Unreal Engine API: C++ and Blueprints visual scripting system
	+ Godot API: GDScript, C#, and GDScript API
* Examples of games built with game engines include:
	+ Unity: Minecraft, Cuphead, and RimWorld
	+ Unreal Engine: Fortnite, Mass Effect, and The Witcher 3
	+ Godot: Hyper Light Drifter, Celeste, and Dead Cells

**Purpose and Benefits**

* Game engines provide a flexible and reusable software platform that provides all the core functionality needed to develop a game application.
* Benefits of using game engines include:
	+ Reduced costs
	+ Simplified development
	+ Rapid development
	+ Platform abstraction
	+ Extensibility
	+ Access to a community of developers and resources
