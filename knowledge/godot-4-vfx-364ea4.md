**Godot 4 VFX Assets**
=======================

**Overview**
------------

The Godot 4 VFX Assets repository provides a collection of free and open-source VFX assets for Godot 4. The assets include particle examples, shaders, and more.

**APIs and Examples**
---------------------

The repository provides various APIs and examples for utilizing the VFX assets in Godot 4. Some notable examples include:

*   **Particle Examples**: A set of particle examples demonstrating how to use the VFX assets in Godot 4.
*   **Shaders**: A collection of shaders that can be used to create custom visual effects in Godot 4.
*   **Materials**: A set of materials that can be used to create realistic textures and effects in Godot 4.

---------------------

*   **`GodotScript` API**: Provides a set of functions and variables for interacting with the VFX assets in Godot 4.
*   **`GLSL` API**: Provides a set of shaders and material scripts for creating custom visual effects in Godot 4.

**Getting Started**
-------------------

To get started with the Godot 4 VFX Assets repository, follow these steps:
