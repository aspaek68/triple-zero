**Procedural Generation**
==========================

**Definition**
---------------

Procedural generation is a method of creating data algorithmically, as opposed to manually, typically through a combination of human-generated content and algorithms coupled with computer-generated randomness and processing power.

**Applications**
----------------

*   **Computer Graphics**: used to create textures, 3D models, and landscapes
*   **Video Games**: used to automatically create large amounts of content, such as levels, textures, and complete worlds
*   **Music**: used to create compositions in various genres of electronic music
*   **Tabletop Role-Playing Games**: used to generate dungeons, terrain, and other world elements

**Types of Procedural Generation**
----------------------------------

*   **Fractals**: geometric patterns that can be generated procedurally
*   **Random Number Generation**: used to generate random numbers, which can be used to create procedural content
*   **Pseudorandom Number Generators**: used to generate pseudorandom numbers, which can be used to create procedural content

**Notable Examples**
--------------------

*   **NetHack**: an early roguelike game that heavily utilized procedural generation
*   **Rogue**: a classic roguelike game that used procedural generation to create dungeons and game content
*   **Maze Craze**: a game that used an algorithm to generate random, top-down mazes for each game
*   **Just Cause**: a game that used procedural generation to create a large and varied group of detailed tropical islands
*   **No Man's Sky**: a game that is entirely based on procedurally generated elements

**Concerns and Limitations**
---------------------------

*   **Procedural Oatmeal**: a term coined by writer Kate Compton, which refers to the lack of perceived uniqueness in procedurally generated content
*   **Infinite Worlds**: a concern that procedural systems can generate infinite numbers of worlds to explore, without sufficient human guidance and rules to guide these

**APIs and Libraries**
----------------------

*   **L-Systems**: a formal grammar system for generating fractals and other geometric patterns
*   **Fractal Libraries**: various libraries and frameworks for generating fractals and other procedural content
*   **Random Number Generation Libraries**: various libraries and frameworks for generating pseudorandom numbers and procedural content
